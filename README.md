# THE FAMILIES — El Museo

Un museo digital navegable para la marca de moda **The Families**. No es una tienda: es un espacio brutalista de concreto donde recorres recuerdos y descubres prendas como esculturas sobre pedestales iluminados.

Opción 2 del sitio (la opción 1 es la landing editorial).

## Stack
- Next.js 16 · TypeScript · Tailwind v4
- Three.js · React Three Fiber · @react-three/drei
- Framer Motion

## Controles
- **Escritorio:** clic para mirar (pointer lock), `W A S D` para caminar, acércate a una prenda para ver su ficha.
- **Táctil:** arrastra para mirar el espacio.

Todo en español, precios en pesos colombianos.

```bash
npm install && npm run dev
```
